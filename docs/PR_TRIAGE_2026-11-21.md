## What this means

1. 139 of the 156 open PRs sit in 14 file groups, so most of the queue is the same handful of files fixed repeatedly by the same bots.
2. The largest groups are the bot journals (`.jules/sentinel.md`, `.jules/bolt.md`, `.Jules/palette.md`) which each PR appends to alongside a code change, so a journal edit alone is not a signal of value.
3. Only 1 PR was byte-identical to main, so the rest still differ. Differing is not the same as useful: several of these are fixes to code that has since been rewritten.
4. PR #471 consolidated every open bot change into one place, which is the argument for closing the superseded sets rather than merging them individually.

## Recommended action

Close every PR except the newest in each group, with the reason recorded on the PR. That retires 125 of 156 and leaves 31 open for review, of which 14 are the newest in their group.

## Not done in this pass

1. No PR was closed. The recommendation above needs an explicit go.
2. Per-PR judgement of whether a specific fix is still correct against current main. Grouping shows where to look, not whether each diff still applies.
3. The 17 PRs outside any group were not reviewed individually.
